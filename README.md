# automation

This repository contains projects built with Devin.

## Projects

### edukenya

A portfolio site for Edu's photo editing / retouching work, where clients can
browse before-and-after edits, view services, and start a project.

- Tech: Vite + React + TypeScript + Tailwind CSS + React Router
- Location: [`edukenya/`](./edukenya)

**Run locally:**

```bash
cd edukenya
npm install
npm run dev
```

**Build for production:**

```bash
cd edukenya
npm run build   # output in edukenya/dist
npm run preview
```

The site is a static SPA and can be deployed to any static host (Vercel,
Netlify, Cloudflare Pages, devinapps, S3, etc.).
